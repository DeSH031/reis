# Движок прибыли

Файл: `src/domain/profit/index.ts`. Тесты: `profit.test.ts`.

## Правила
1. Деньги считаются в целых тиынах. Округление выполняется один раз, при переводе ставки в тиыны и при вычитании НДС.
2. Неизвестное остаётся неизвестным. Если рейс доставлен, но нет топлива и зарплаты водителя (или суммы перевозчику для рейса на субподряд), прибыль = `null`, рейс помечен `incomplete` и не входит в итоговые суммы.
3. Прибыль считается только для статусов «доставлен», «документы», «оплачен». У отменённых рейсов расходы и прибыль не учитываются.
4. Если НДС включён в ставку, а ставка НДС в настройках не задана, выручка неизвестна (`revenueUnknown`), прибыль не считается.
5. Оценочные расходы (`source = estimated`) входят в расчёт, но рейс получает флаг `estimated`, и это видно в карточке.

## Формулы
- Выручка без НДС: `incl` → `цена / (1 + НДС%)`, иначе цена.
- Известная прибыль = выручка без НДС − сумма расходов.
- Маржа = прибыль / выручка. Прибыль на км = прибыль / км с грузом.
- Агрегат (`aggregate`) суммирует только рейсы с известной прибылью и отдельно считает рейсы без данных.

## Часовой пояс
Границы суток считаются в Asia/Almaty (`almatyDayKey`).
