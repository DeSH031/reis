# Сценарий демо (10 минут)

1. **Вход.** Главная, «Войти в демо». Сказать: данные вымышленные, 300 рейсов за полгода.
2. **Обзор.** Известная прибыль за 30 дней, сколько рейсов с полными данными. Показать, что 9 рейсов помечены «без данных по расходам»: система не выдумывает прибыль.
3. **Рейсы.** Таблица, фильтр по статусу, канбан. Открыть убыточный рейс Атырау → Актобе: видно, из чего сложился минус.
4. **Быстрый ввод.** «Новый рейс», в строке быстрого ввода написать «Алматы Астана завтра 22 т 600000 Нур Строй», проверить поля, создать.
5. **Расходы.** В карточке добавить топливо и зарплату водителя, сменить статус на «Доставлен»: появилась прибыль и маржа.
6. **Водитель.** Кнопка «Ссылка для водителя», открыть ссылку с телефона: водитель отмечает выезд и расходы.
7. **Финансы.** Просроченные счета по клиентам, внести платёж.
8. **Оповещения.** Срочные: убыточные рейсы и просрочки.
9. **Итог.** Что получает владелец: видит прибыль по каждому рейсу и не теряет деньги на просрочках.
