# Решения

- Деньги: numeric(14,2) в БД, целые тиыны в расчётах, округление один раз.
- НДС, цена топлива, суточные, амортизация: только настройки организации. В демо-организации стоят помеченные демо-значения (НДС 12 %, топливо 300 ₸/л). Перед работой с реальным клиентом проверить актуальную ставку НДС.
- Политики RLS разделены на insert/update/delete (без «for all»), чтобы не плодить лишние permissive-политики на select.
- Диспетчер тоже может создавать документы (пакет документов по рейсу в один клик); блокировку подписанных документов и разблокировку делает бухгалтер или владелец.
- Функции is_org_member/has_org_role доступны роли authenticated намеренно: на них опираются политики RLS. Advisor предупреждает об этом, это принятый риск (функции только читают членство текущего пользователя).
- Таблицы doc_counters, driver_links, telegram_link_codes без политик: доступ только через service role.
- Демо-сид: функция seed_demo(org) в БД, детерминированная (хэши вместо random), вызывается и из действия «Сбросить демо».
- Демо-токен водителя: `demo-live-driver-token` (хранится только sha256). Это известное демо-значение, для реальных рейсов токены случайные.

- Next.js 16: включённый по умолчанию cacheComponents отключён (все страницы читают сессию на запросе). Tailwind подключается правилом turbopack из next.config.ts.
- UI-компоненты написаны вручную на Tailwind в src/core/ui (shadcn/ui пока не подключён).
- Приложение не использует service role там, где можно обойтись RPC: reset_demo(), issue_doc_number() работают от имени пользователя.
