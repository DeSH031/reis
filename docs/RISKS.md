# Риски

| Риск | Что делаем |
|---|---|
| Неполные данные по расходам дают ложную прибыль | Прибыль не показывается, пока нет топлива и зарплаты водителя; рейс помечен |
| Анонимный доступ по ссылке водителя | Токен 32 символа из двух UUID, в базе только хэш, срок 14 дней, водителю не показываются ставка и клиент |
| Утечка данных между организациями | RLS на всех таблицах по `org_id` |
| Двойная нумерация документов | Номер выдаёт функция в базе, атомарно |
| Ключ service role | Нужен только для cron; хранится в переменных Vercel, в коде не используется для пользовательских запросов |
| Лимиты Vercel Hobby | Один cron в сутки, отчёт раз в день |
| Seed-данные выглядят как реальные | Организация названа «(демо)», на каждой странице баннер |
